# BardsTaleKnockOff

* I made the treasure image from Clint Bellanger's treasure set (CC-BY-SA) (https://opengameart.org/content/gold-treasure-icons)
* The treasure chest art is CC0 and originally from https://foozlecc.itch.io/chest-and-key-pack
